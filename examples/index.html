Form validation: examples

Four forms checked while you type, with the schemas in examples/forms.js. The server (npm run examples) checks the same schemas: Send as is skips the browser's checks, so you see the server's answer in the same message lines.

Opened from disk: browsers don't run module scripts from file://. Run npm run examples and open http://localhost:5178/examples/.

Billing

Choose A company: its fields appear and City and Address become required. Type a VAT number for Bulgaria, then change the country. City "1" and Address "1" no longer pass.
