Look designer

Tune the fields on real forms, then export the result for another project. The forms are styled with the CSS that gets exported, so what you see is what you get. Their schemas are in examples/forms.js, and the server checks the same schemas: Send as is skips the browser's checks, so you see the server's answer in the same message lines.

Opened from disk: browsers don't run module scripts from file://. Run npm run examples and open http://localhost:5178/examples/.
